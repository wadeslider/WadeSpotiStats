FUENTES DE DATOS

iTunes + MyStreamCount

iTunes completa metadatos y portadas. MyStreamCount aporta los streams mediante una consulta automática.

La biblioteca se revisa todos los días a las 9:00 a. m. y las canciones nuevas o editadas se consultan al guardarlas. La hora usa la zona horaria de tu dispositivo.
Última revisión automáticaPendiente

GitHub Pages no ejecuta tareas con la web cerrada. Si abres la app después de las 9:00 a. m., realizará la revisión pendiente.

ALMACENAMIENTO

Solo este navegador

Los datos se guardan en localStorage. No se suben a un servidor ni se sincronizan automáticamente entre dispositivos.
